* issue_tracker:
    * 이슈가 생겼을 경우 내역을 적습니다.
* project_progress:
    * 진행 상황을 적습니다.

- Status Required Options List
    - Progress : 작업 진행 중
    - Debug Reporting : 일반적인 버그
    - Solved / Fin : 해결된 문제 / 닫힌 문제
    - Need to Help : 도움이 필요함
    - Caution : 신중하게 작업해야 함.
    - Critical : 치명적인 요소. (보안 등)
    - Important: 매우 중요함.
    - Reload (n) : 다시 발생한 문제 (횟수)
    - Remained ... : 남아있는 문제
    - Hold off : 보류
    - Not Urgent : 급하지 않음
