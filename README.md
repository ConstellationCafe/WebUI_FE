# Constellation Cafe

## Design Pattern

- 어떤 기능을 사용하시나요?
* 사용자 영역 / 관리자 영역
* 친선전 게시판
* 관리자 통계 영역

- 어떤 테마를 사용하시나요?
* Primary Color:
* Secondary Color:
* Tertiary Color:
  (Color에 대해 잘 모른다면 Adobe Color 홈페이지)

- 어떤 폰트를 사용하시나요?
Noto Sans KR (기본 - 한국어)

- 반응형 홈페이지
와이드 (X) / 랩톱(기본) - under 1350 / 태블릿 (X) - under 900 / 모바일 (기본) - under 450

- Required Assets List
필요한 에셋들의 리스트를 적어주세요.
  (에셋: 우리가 가지고 있는 이미지, 아이콘, 그림 등)
  (기본적인 아이콘 등은 Material Design에서 기본적으로 제공해줌)

- Category 설계 (어디까지 검색에 드러나야 하는 영역인지 / 어디까지 묶여야 하는 테이블인지)
  * Category, Search Bar, Tags가 통합된 검색 (쇼핑몰, 포털 등에 적합)
  * Tags 및 HyperText의 강화 (위키, 블로그 등에 적합)

- Web Database 구조화
* 계정 및 로그인 (현재 하지 않음)
* UID 등록을 통해 드러낼 정보 및 영역 (Public - Private 영역 분리)
